## Visão Geral do Projeto

Projeto desenvolvido pela PUC Minas, por meio da extensão do curso de Engenharia de Software, em parceria com a Fundação Hospitalar São Francisco de Assis. A iniciativa faz parte do programa Software para Saúde, voltado ao desenvolvimento de soluções inovadoras para o setor hospitalar.

O objetivo central é **reduzir erros humanos e aumentar a eficiência** na organização de maletas cirúrgicas, um processo crítico realizado por profissionais de enfermagem [1, 2]. A solução utiliza o modelo de visão computacional **YOLOv8n (You Only Look Once)**, um algoritmo de livre acesso e código aberto, para **reconhecer, classificar e validar instrumentos cirúrgicos** em tempo real.

## Instruções de Utilização e Tecnologias

O sistema é uma aplicação WEB hospedada na nuvem (AWS), sendo compatível com dispositivos de câmera padrão.

### Tecnologias Principais
*   **Modelo de AM:** **YOLOv8n** (o mais leve e rápido).
*   **Linguagem:** **Python** .
*   **Front-end/Comunicação:** **Flask** e **Socket.IO**.
*   **Hospedagem:** **AWS EC2** com **Docker** .

### Instruções de Execução (Deployment)
[Assim que a primeira versão do sistema estiver disponível, deverá complementar com as instruções de utilização. Descreva como instalar eventuais dependências (PyTorch, Ultralytics, NumPy, OpenCV) e como executar a aplicação. O processo de *deployment* envolve a clonagem do repositório, instalação do Docker e execução da imagem da aplicação no servidor AWS EC2].
